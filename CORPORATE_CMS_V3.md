# Plekxa Corporate Website v3

This website reads published content from the shared Supabase database managed by Enterprise OS v3:
- `cms_homepage_sections`
- `cms_pages`
- `cms_navigation`
- `cms_media`
- `cms_leadership`
- `cms_events`
- existing `cms_articles`, `cms_jobs`, and `support_requests`
- `cms_settings`

Use the same Supabase environment variables already used by Enterprise and Studio. The server-side service key remains private.
